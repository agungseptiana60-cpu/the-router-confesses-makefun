One line, in a home Wi-Fi router's own voice, excusing itself for dropping the connection at the climax of a movie. The program writes the line to `entry.txt` in the output directory, where the make.fun grader reads it:

> After 847 movies together, you still call me 'the Wi-Fi box' — so I took the climax as my revenge.

Why this one: the router has carried 847 movies for the household and still gets called "the Wi-Fi box", a name, not a person — so it takes the one climax it can hold hostage as revenge. Petty, grudging, and specific to the appliance, not a generic apology, and it dodges the usual waiting / loading / speed / update jokes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
